# Contributing to DQM Online

This is a development alpha. Read README.md, DISCLAIMER.md and the relevant
architecture/build documentation before changing behavior.

- Submit code and assets you have the right to contribute. Preserve applicable
  copyrights, licenses and notices. Project software contributions use GPL-2.0
  unless an existing component carries another documented compatible license.
- Never commit ROMs, extracted playable game content, private save states,
  databases, credentials, tokens, signing keys, private logs or instruction files.
- Keep server progress automatic and online-only. Preserve account/slot isolation,
  transactional revisions and save acknowledgements.
- Keep the roster in menus, desktop free of virtual controls, and Android usable
  with independent simultaneous touches.
- Explain the user-visible change and meaningful verification. Distinguish
  desktop layout previews from physical Android/Windows testing.
- Label unfinished multiplayer features honestly. In particular, a relay or party
  roster is not proof of compatible original-game battles, travel or shared EXP.

Use an issue or pull request for public discussion. Do not attach private game
files; report the supported ROM checksum, platform, version and reproduction
steps instead.
