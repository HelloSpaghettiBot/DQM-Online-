SOURCE / LICENSES

Yours to explore.

DQMOnline is distributed under the GNU General Public License, version 2. The source download includes build instructions, the native emulator bridge, the Godot projects, the server, the website, and the patches needed to reproduce the build.

The emulator is based on Gambatte. Godot and godot-cpp use the MIT license; the SQLite extension also uses the MIT license. Their notices and pinned dependency sources are documented in the source archive.

Client

Original-engine campaign play, desktop input, larger Android D-pad and analog controls, online-only adventure loading, multiplayer HUD, and a verified-download updater.

Server

Authenticated player sessions, chat, invitation consent, cable relay, and transactional account-isolated server adventures.

Website

Registration, account login, release downloads, and server status, hosted on the same VPS.

The software license does not grant rights to the original game or screenshots. Read the project disclaimer.

What you will not find

No commercial ROMs, playable extracted maps or sprites, music, account databases, credentials, private logs, saves, or signing keys are included. The website assets include the gameplay screenshots shown on these pages. Every player supplies their own compatible ROM locally.

Current engineering priorities

Extend server-side gameplay and economy validation, verify the nearby-player display across the campaign, complete original link-battle and trade tests, verify multiplayer breeding, and test exported clients on real Windows and Android devices.
