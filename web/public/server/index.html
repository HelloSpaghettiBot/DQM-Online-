CONNECTION / STATUS

Get connected.

  1. Create an account in the client through Menu → Account → Create account, or use the main page.
  2. Download a client for your platform.
  3. Select your local, unmodified Cobi’s Journey USA ROM when prompted. Android can stretch the game to fill the screen through Menu → Settings.
  4. Open Menu → Account, keep 403world.com as the server, and enter your account name and password.
  5. Choose Continue for a saved adventure, or New adventure to begin.

Website login and the game connection use HTTPS. No VPN setup is required. ROM data and its hash stay on your device. After login, choose an adventure to load your account’s progress from the server. An active connection is required to play.

Available in this alpha

Online-only campaign play, three account-isolated server adventure slots, automatic server saves, account login, chat, a menu-based player list, and an initial nearby-player overlay. Shared-world presence is currently client-reported and is not a cheat-resistant authoritative MMO.

Still in development

Original in-game PvP, trading, and multiplayer breeding are not verified end to end. The network cable bridge passes a hardware-level test, but this does not establish full game compatibility. The latest server checkpoint remains the recovery point for interrupted sessions.

Farm start

New adventures start at the family farm after the boat intro. Existing saved progress is preserved. Choose a fresh adventure slot if you want the new start.

Client updates

Version 0.2 clients check for new releases automatically. Desktop clients save and restart with the update. Android downloads the verified APK and opens the system installer for confirmation. Install 0.2 manually once to enable future updates.

Save data

Your adventure is saved on the server every five seconds, including its resume position. Progress is saved automatically during play, when switching adventures, and when logging out or quitting. No manual save action is required. Disconnecting stops gameplay; sign in again to load the last confirmed checkpoint. Progress after that checkpoint may be lost during an unexpected interruption. Existing server cartridge backups migrate to Adventure 1; old local saves are not used. Server save data is private and never included in downloads.
