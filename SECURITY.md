# Reporting security issues

Do not publish passwords, login tickets, signing keys, account databases,
private saves, exploit payloads against the live service, or other users' data.

For a suspected vulnerability, contact the repository maintainer through GitHub
and request a private reporting route before sharing sensitive details. If the
repository offers GitHub's private vulnerability-reporting button, use it.
Do not assume that feature is enabled. A public issue should contain only a
nonsensitive request for contact, not an exploit or private material.

The current release is a development alpha. Original game simulation is local;
server save authentication does not provide a cheat-resistant economy. No bug
bounty, response-time guarantee or legal safe-harbor program is implied.
